導入前によくある質問

WindowsでもMacでもOBS Studioで動きますか？

はい。OBS Studio標準搭載のブラウザソースおよびカスタムブラウザドックのみで動作するため、Windows / macOS どちらでも外部プラグイン不要でそのまま動きます。

セットリストや作業タスクの内容が外部に送信されませんか？

一切送信されません。お使いのPCのOBSブラウザ内（BroadcastChannel と localStorage）だけで完結する設計のため、未公開の新曲セトリも安心して準備できます。

収益化済みチャンネルや事務所所属ライバーでも使えますか？

はい！個人勢・企業/事務所所属を問わず、スーパーチャットやメンバーシップを含む商用・収益化配信で追加費用なくご利用いただけます。

歌枠の開始時刻とタイマー押下がズレた場合は直せますか？

Pro版では「±1秒 / ±5秒 / ±10秒」のオフセット微調整ボタンを搭載しており、全曲のタイムスタンプをまとめて実際のアーカイブ秒数へピッタリ合わせられます。
